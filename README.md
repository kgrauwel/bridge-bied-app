# Bridge Bied App

Cloudflare Worker voor online bridge bieden met deelbare sessies, meerdere paren, dezelfde handen, par-info en chat.

Cloudflare build settings:
- Build command: leeg laten
- Deploy command: npm run deploy
- Root directory: leeg laten

Na de eerste deploy: maak een D1 database en voeg binding DB toe aan de Worker.
